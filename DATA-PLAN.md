# Data Plan

No external data sources: the artifact is populated by user input and its own actions. If that changes, finalize the plan again with a `data_plan` object carrying the `markdown` body.

## Latte-art ranking (added 2026-11-08)

Head-to-head ranking, art only: migration `0003_add_latte_art_elo_rankings.sql` adds internal Elo columns (`art_elo`, `art_wins`, `art_losses`, `art_comparisons`) to `lattes` and a `latte_comparisons` history table — no existing rows or photo blobs are touched. Existing pours were seeded in-place from their stored 1–5 `latte_art_quality` (1500 + (rating − 3) × 80; unrated pours stay at the 1500 baseline). The UI never shows raw Elo: the server maps it to a 0–10 score (1500 → 5.0). New pours with photos get a placement session against similarly scored pours; a rerank/calibration mode and a reset-to-seed action live in the Art rankings section.

## Win/loss restored, sticky progress fixed, milk quality replaces art rating (2026-11-08)

Win/loss records are displayed again everywhere a pour appears: under the art-score chip in the ranked list, the not-ranked list, and the journal (W · L plus match count), in the expanded entry detail (wins · losses · matchups next to the art score), and on head-to-head matchup cards. The counters were always stored and returned by `listLattes`; only the display had been removed.

Desktop layout restructured so "Your progress" no longer floats down the whole page: the intro + entry form + progress now live in an `.entry-layout` grid (two columns on ≥980px, `display: contents` with flex ordering below that, preserving the phone stacking order). The progress panel is sticky inside its own `.progress-column` wrapper, whose height is exactly the entry column's height, so it floats alongside the entry box and settles at the entry box's bottom edge instead of following the rankings/journal. (The intro section itself was removed in the same pass — the page now opens straight on the entry form.)

Migration `0004_add_milk_quality_rating.sql` adds a nullable `milk_quality` column (1–5, how well the milk was steamed) — separate from the `milk` milk-type text field, which is unchanged. The 1–5 `latte_art_quality` rating is retired: no longer entered, shown, or used anywhere (the column stays in the table so old rows keep their history). The 0–10 matchup score is now the single art rating; new pours start at the 1500 baseline (5.0), and "Reset scores" resets everyone to that baseline instead of the old art-rating seeds. Existing pours' current 0–10 scores, Elo values, and win/loss records are untouched by the migration.

Also in this pass: the entry form is more compact (tighter paddings, 84px photo tiles, 40px rating buttons, shorter notes box), dark-mode button contrast is fixed via `--button-bg`/`--button-text`/`--accent-text`/`--danger-text` tokens (primary buttons were near-white text on the light cream `--text` fill in dark mode), and the Your progress section gained a short flavor line (pours logged, matchups played, best art score) computed from the live journal.

## Title kept (2026-11-08)

The page heading "Make this cup count." is kept as the title at the top of the entry column. The descriptive paragraph that previously sat under it ("Capture the pour while it's fresh…") stays removed per the earlier request — only the title heading itself is restored, using the existing `.morning-intro` styling.

## Rerank label, prominent expanded art record, photo viewer (2026-11-08)

The per-pour placement button is now labelled "Rerank this pour". Collapsed rows show the record tersely — score chip plus a bare win–loss line (e.g. "3–2", no W/L suffixes) and the matchup count — while expanded entries lead with a prominent art hero: an oversized 0–10 score chip beside large win/loss text and the matchup count. Tapping any photo in an expanded entry opens a full-screen viewer: pinch-to-zoom and drag-to-pan on mobile (double-tap toggles zoom), a large centred popup with wheel zoom and zoom/prev/next controls on desktop; Esc, the close button, or the dimmed backdrop closes it, and arrow keys move between a pour's photos. No data or action changes: rerank sessions, comparison recording, and counters are unchanged, and bailing out mid-session ("Done ranking") simply ends the session — picks already made stay recorded, unplayed matchups record nothing.

## No brand name in the UI (2026-11-08)

Per the user's request, the word "Beli" no longer appears anywhere in the UI (it had been in the matchup hint and the Art rankings intro, both now reworded to plain "art score" language). The same wording was also scrubbed from server action descriptions and code comments so nothing user-facing or agent-facing carries the name. No behavior or data changed.

## Editing entries (added 2026-11-08)

Every entry can now be edited in place: expanding a pour in the Art rankings or the journal shows an "Edit entry" button that opens an inline editor (same shared detail renderer, so both lists behave identically) covering every user-entered field — made-at date/time, location, milk type, espresso / milk-quality / overall 1–5 ratings (tap a selected rating again to clear it), and notes — plus photos: add new photos (camera or library, normalized to JPEG like the composer), remove existing or newly added photos, and reorder photos with earlier/later arrows, capped at 8 total. Save persists through the new owner-only `updateLatte` action, which validates that every kept photo belongs to the entry, reorders kept photos to the sent order, appends new photo blobs after them, deletes removed photo rows and blobs, and cleans up new blobs if the save fails. Cancel discards all in-form changes (including revoking new-photo previews) and leaves the stored entry untouched. The 0–10 art score, win/loss record, and matchup history are deliberately not editable — the editor shows the art hero with a note that the score is earned through matchups. No schema change or migration was needed, and no existing rows, scores, or photos were modified by adding this capability.

## Rankings as primary record (updated 2026-11-08)

The Art rankings section is now the primary record: it renders first among the record sections, and every ranked pour (plus photo-less pours under a "Not ranked" subheading) is a tappable row that expands to the same detail as the chronological journal — all photos, the espresso/art/overall ratings, notes, "Rank this pour", and the same two-step delete. The journal keeps its own expand state, so both lists behave identically. Match counts and win/loss records are no longer displayed anywhere (win/loss/comparison counters remain server-side only, where matchup suggestion uses them). Deletion was verified and hardened: `deleteLatte` now rejects a missing id, removes the pour's comparison rows, photo rows, latte row, and photo blobs, and decrements each former opponent's win/loss/comparison counters by the removed matchups so surviving records stay consistent.

## Score recompute fixes pre-rollback drift (2026-11-08)

Two pours still carried drift from test matchups deleted before the delete-rollback fix existed (pour #6 at 4.77, pour #11 at 6.7), with no comparison rows left to roll back from. The new `recomputeArtScores` action rebuilds every art score by replaying the 10 surviving comparisons in chronological order (created_at, then id): each pour starts from the Elo "before" value stored in its first surviving matchup — the baseline it held right after the reset, before the re-rank (the re-rank was played from those stored starting scores, e.g. 1580/1420/1500, not one uniform value, so fresh swings are never recomputed from winner/loser alone) — and accumulates each matchup's stored swing (after − before). Only `art_elo` is written, and only where it differs; win/loss/comparison counters and the comparison history rows are untouched, no rankings are reset. Verified against a copy of the live data: #6 returns to exactly 5.0 (Elo 1500) and #11 to exactly 6.55 (Elo 1611), every other pour's score is unchanged (5.46 / 4.77 / 5.23 / 3.69 / 5.69 / 6.35 / 5.19 / 4.77 / 4.77 / 5.92 / 6.13), the action is idempotent (a second run changes nothing), and totals stay at 13 lattes / 13 photos / 10 comparisons. The action runs once against the production database as this build's post-submit action; it accepts the owner or the platform's viewer-less system invocation, and still blocks any signed-in non-owner viewer.

## Deletion rolls back opponents' art scores (2026-11-08)

Live testing found that deletion restored opponents' counters but not their art scores: a deleted test pour's win over pour #6 left #6 at 4.77 instead of its pre-match 5.0, and its loss to #11 left #11 at 6.7 instead of 6.55. `deleteLatte` now also rolls back each former opponent's Elo by exactly the swing that opponent gained or lost in the removed matchups — the comparison rows already store both pours' Elo before and after (`winner_elo_before/after`, `loser_elo_before/after`), so the opponent's swing per matchup is (after − before), accumulated across all removed matchups against that opponent and subtracted from their current Elo on delete. No other pour's score changes, no scores are reset, and the user's re-ranked scores from surviving matchups are preserved exactly. No schema change or migration was needed.
